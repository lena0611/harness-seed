# /하네스용어

**용어 정본은 `.harness/project/terminology.md`입니다.** 이 파일은 Claude Code 진입점(어댑터)이며, 조회 전용입니다 — 이 명령은 어떤 파일도 수정하지 않습니다.

인자: `$ARGUMENTS` — 용어나 키워드가 오면 그 항목만, 없으면 전체를 보여줍니다.

## 순서

1. `.harness/project/terminology.md`를 읽습니다. 이 파일 밖의 정의를 지어내지 않습니다.
2. **인자가 있으면**: 용어 열과 설명 열에서 부분 일치로 찾아 해당 행만 표로 보여줍니다.
   여러 절에서 걸리면 절 이름(일하는 방식 / 검증·차단 / 기획 연동 / 계층·계약)을 함께 표기합니다.
3. **인자가 없으면**: 정본의 절 구성 그대로 표 전체를 보여줍니다. 표가 길어도 요약하거나
   생략하지 않습니다 — 정본을 그대로 비추는 것이 이 명령의 일입니다.
4. 표에는 정본의 **실물(파일 경로·명령) 열을 반드시 유지**합니다. 용어 설명만 주고
   끝내지 않습니다 — 개발자가 바로 열어볼 수 있는 경로가 이 명령의 존재 이유입니다.
5. 마지막에 한 줄로 정본 위치를 안내합니다:
   "정본: `.harness/project/terminology.md` — 용어 추가·수정은 이 파일에서."

## 기준

- 정본에 없는 용어를 물으면 없다고 말하고, 뜻을 추측해 답하지 않습니다. 대신 관련이
  있어 보이는 기존 항목이나 문서(`.harness/project/*`, `.harness/policy/*`)를 후보로
  안내합니다.
- 정본에 없는 용어가 하네스 문서·대화에서 반복적으로 쓰이고 있다면, 정본 등재 후보라고
  알립니다 — 등재 여부는 개발자가 정하고, 수정은 별도 지시로만 진행합니다.
- 프로젝트 로컬 용어(도메인 용어)는 이 명령의 범위 밖입니다 — `.harness/project/domain-rules.md`를
  안내합니다.
