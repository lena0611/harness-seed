## 변경 규칙
- 규칙을 추가하면 그 규칙을 잡는 도구 설정이 있는지 함께 확인합니다. 도구가 잡는 규칙은 문서보다 도구가 정본입니다.
- 기존 코드를 규약만으로 일괄 정리하지 않습니다 — 신규·수정 코드에 적용합니다.
- 코딩 규약이 스택 기준과 충돌하면 적용 범위와 예외를 명시하고 `decision-log.md`에 이유를 남깁니다.
