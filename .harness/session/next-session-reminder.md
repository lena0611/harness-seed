### 검증 CI 제거 (결정 114)

- **원격 코드 검증 CI 는 이제 없습니다.** 검증은 로컬 훅이 전부 합니다 — pre-commit 이 정책·문서·계약, **pre-push 가 회귀 전량**. GitLab `.gitlab-ci.yml` 은 태그 push 공지 잡 하나로 그대로입니다.
- 근거: 우분투 러너가 대표하는 개발자 0명(맥·윈도우뿐, 윈도우는 Git Bash) · CI 가 잡은 두 건 모두 소비자 영향 0건 · 6번 연속 빨강이 사람에게 닿지 않았음 · 유일한 검증 CI 가 개인 GitHub 계정에 매달려 있었음.
- **포기한 값 하나**: 새 clone + `npm install` 검증. 실제로 물리면 맥 러너(선택지 B)로 되살립니다.
- 릴리스 체크리스트에서 "push 후 CI 확인"이 빠졌습니다. **커밋만 하고 끝내면 회귀가 한 번도 안 돕니다** — pre-push 가 유일한 실행 지점입니다.
